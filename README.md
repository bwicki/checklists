# SBA Checklisten

Ballon-Checklisten je Flugzustand als installierbare Web-App (PWA) mit Protokoll je Nutzer und
Admin-Desktop – für die Swiss Ballooning Academy.

- Website: https://checklists.wicki.aero
- Einrichtung: `SETUP.md` (GitHub Pages, Cloudflare Worker über den Workflow «Setup worker»)
- Pflichtenheft: `docs/Pflichtenheft_Checklisten_v0.1.docx`
- Worker (API, D1, R2): `worker/` · Schema `worker/schema.sql`
- Logos: `assets/`

Stand: Grundgerüst v0.1 (Schema, Worker-Gesundheitsprüfung, Setup-Workflow). Die App folgt mit v0.1.0.
